# AuraLuz Semijoias — LP de recrutamento

MVP da landing page para recrutamento e qualificação de parceiras de revenda por consignação.

## Rotas do GitHub Pages

- `/` — landing page de recrutamento.
- `/briefing-producao/` — apresentação visual com informações, fotos e vídeos necessários para concluir a LP.

Depois de ativar **Settings → Pages → Deploy from a branch → main / root**, as rotas serão:

- `https://33kilates.github.io/auraluz/`
- `https://33kilates.github.io/auraluz/briefing-producao/`

## Pendências antes do tráfego

Consulte `README-MVP.md` para integrações e validações necessárias. O formulário permanece em modo de demonstração enquanto `ROUTING_ENDPOINT`, `WHATSAPP_NUMBER` e `PRIVACY_POLICY_URL` estiverem vazios.
